======================
TECH STACK
======================
Framework: Next.js 16.1.1 + React 18.3.1
Styling: Tailwind CSS 3.4.17
Web3: Wagmi 3.1.3, Viem 2.43.4
State: TanStack React Query 5.59.15
Icons: Lucide React 0.441.0
Graphics: Three.js 0.169.0 (available, not actively used)

======================
DESIGN THEME
======================
Art Deco / Art Nouveau aesthetic
- Warm palette: Burgundy (#a52b36), Gold (#f6c25d), Cream, Sage
- Cool palette: Slate (#3f647e), Teal (#00b0b2), Ivory, Charcoal
- Geometric patterns: Sunburst, chevron, diamond lattice
- Fonts: DM Sans (body), Poiret One (headings), Cormorant Garamond (display)
- Animations: shimmer-gold, pulse-soft, fade-in

======================
KEY FEATURES
======================
1. Meta-Transaction Execution (x402 Protocol)
   - Target contract + calldata input
   - Priority tiers: Économique/Slow, Standard/Normal, Prioritaire/Fast
   - Transaction status + Cronoscan explorer links

2. Dashboard Control Panel
   - Relayer status monitoring
   - Live metrics (CRO balance, USDC earned, gas price, tx count)
   - Recent transaction tracking

3. Settings System (localStorage-based)
   - Theme selection: Parisian Light, Noir, Midnight Teal
   - Default gas tier preference
   - Sound effects toggle

4. Notification System (event-driven)
   - Types: success, error, pending, info
   - Unread badge, mark as read, clear all
   - Max 50 notifications in-memory

======================
STATE MANAGEMENT
======================
- React Query: Server state (API calls, health, faucet, meta-tx relay)
- useState: Local component state (forms, UI, loading, tx hashes)
- localStorage: Persisted settings (theme, gas tier, sound)
- In-memory: Notification store with event listeners

======================
DATA FLOW
======================
User UI (Pages/Components)
  ↓
Local State (useState) + localStorage
  ↓
API Client (lib/api.ts)
  ↓
React Query (QueryClientProvider)
  ↓
Wagmi (WagmiProvider) for Web3
  ↓
Backend APIs (Meta-tx relay, Faucet, Health)
